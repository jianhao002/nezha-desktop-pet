# 焰轮哪吒 v0.9.2

本次将已经本机试玩的 0.8.2 至 0.9.2 内容统一正式发布。已有 GitHub 版可从桌宠右键或托盘菜单的“检查更新”升级。

## 新增三款离线游戏

- **格子王国 · Gridland**：白天三消采集和建设，夜间迎战怪物；保留本局、成长与死亡后手动继续。
- **小黑屋 · A Dark Room**：从生火、经营村庄逐步发展到出村探索，默认中文。
- **糖果盒子 2 · Candy Box 2**：从积攒糖果开始解锁地图、装备和冒险，保留原作中文提示与字符画。

内置游戏共十六款，都在现有小游戏窗口运行；保留置顶、透明度、切走暂停和收起功能。取消“切走暂停”后，打开的游戏可继续运行；退出桌宠后不补算离线收益。

## 小黑屋修复

- 修复“出发后物资减少，却没有地图”：出发显示地图，回村恢复准备页，遇险返回房间。
- 地图可滚动查看，移动和调整窗口大小时自动居中显示人物。方向键或 WASD 移动，`@` 是你，`A` 是村庄。
- 重开确认、随机事件、战斗弹框适应小窗口，长内容可纵向滚动；补齐 197 条事件中文，跳过离线版无法访问的联网推广事件。

## 安装与进度

首次安装请完整解压 ZIP，运行 `NezhaPet.exe`。已有 GitHub 版可直接检查更新；旧极狐版首次切换 GitHub，按仓库的迁移说明手动安装完整新版。

升级保留本机的 `data`、`games` 和 `.update`。重新打开网页游戏后点“继续游戏”；Candy Box 2 回到糖果页面，小黑屋的探索和事件沿用原作加载规则，不承诺逐帧恢复当前战斗或事件现场。跨电脑迁移个人进度时，先正常退出，再复制整个 `data`。

三款网页游戏需要 Microsoft Edge WebView2 Runtime；本机已有时直接使用，缺少时会提示。其余十三款游戏不要求该组件。日常离线游玩不需要 GPT 账号、Git、Node.js 或服务器。

第三方游戏的原作源码、修改说明与许可均随公开仓库提供，许可也随程序内置。Gridland 和 A Dark Room 使用 MPL-2.0，Candy Box 2 使用 GPL-3.0-or-later；原作者未为本桌面适配背书。

## 验证范围

发布候选包已通过完整本机检查，包括真实出发按钮、地图移动和补给、回村、遇险返回、四种小窗尺寸、进度恢复，以及更新安装 / 失败回滚 / 存档保护。仍需在其他电脑确认显示缩放与长局体验；没有把本机自动化检查视为全部后期剧情的人工通关。
