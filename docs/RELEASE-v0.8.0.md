# 0.8.0 试玩版：格子王国

2026-10-13 本机候选版本。正式 GitHub 更新仍为 0.7.0，本版先在固定试玩目录体验。

## 新增内容

- 第十四款游戏“格子王国 · Gridland”：在现有小游戏小窗里玩三消、白天建设和夜间战斗。
- 中文菜单、离线资源、静音启动；沿用窗口透明度、切走暂停和收起。
- 保存本局棋盘、成长、资源、昼夜进度、人物 / 怪物血量与位置、法术剩余时间；重开后点击“继续游戏”。
- 窗口需要 Microsoft Edge WebView2 Runtime，缺少时给出提示；原十三款游戏继续使用原来的 C# 实现。

## 保存与接入说明

规则快照交给既有原子写入流程，正常退出后可续局。短暂攻击 / 搬运 / 建设动画重建，搬运资源回到保存的仓库，临时飞行投射物不保存。原游戏“导出成长”不能导出桌面完整本局；搬电脑仍复制整个 `data`。

网页、图片和固定版本 SDK 随 exe 内置，更新 ZIP 保持原有程序 / 配置 / README / 素材格式，不替换用户 `data`、`games` 和 `.update`。原作署名、MPL-2.0 源码及 WebView2 许可随仓库和程序提供。

## 本次验证

- 完整 `scripts/Test.ps1`：养成、窗口、食物、动作、更新、原小游戏、网页游戏与四项真实更新助手集成全部通过。
- 真正的 WebView2 测试：实际格子交换 / 消除 / 补齐、暂停保存、控件关闭重开、夜间怪物和法术恢复、三个小窗尺寸通过；另外一个新进程恢复同一棋盘和战斗通过。
- 实际 0.8.0 ZIP 经过当前更新代码解压验收，并用未修改的 0.7.0 更新代码解压通过。

本机 x64 Windows 已验证；其他电脑、ARM64、多显示器和不同缩放比例仍需实机试玩。玩法手感与整条长局尚需用户体验。
