# 焰轮哪吒 v0.7.0

新增四款小游戏，内置游戏由九款扩充至十三款，并支持退出后继续上一局。

## 新游戏

- **莲宝连连看**：三档棋盘，无倒计时。点两个相同图案，连线最多两次转弯，可绕棋盘外侧；提供提示和每局三次洗牌。
- **莲火消消乐**：三色、四色、五色。点击成片同色方块消除，方块下落并收拢空列，全部清空加分；可撤销最近二十步。
- **纸牌接龙**：翻一张或翻三张，红黑交替降序排列，空列只放 K；点牌或牌组，再点目标列，点花色从 A 向上收牌。支持提示、撤销，建议普通窗口模式。
- **哪吒点莲灯**：5×5、7×7、9×9。左键旋转线路，让中心莲火连通全部灯；右键锁定已经确定的格子。

## 继续上一局

十三款内置游戏均可在返回列表、关闭游戏窗口或正常退出桌宠后保存未结束的一局，再打开同一游戏自动继续。每款各保存一局，点击“新一局”重新开始。

保存棋盘、分数、步数、难度、翻牌状态、蛇身与方向、当前方块和下一块、球与挡板状态，以及纸牌 / 消消乐的撤销历史。贪吃蛇、方块、打砖块恢复后先暂停，点击“继续”再开始。退出期间不计入扫雷和数独的用时。

每五秒自动保存，正常退出前再次保存。存档采用临时文件、原子替换与备份；读取失败会提示并保留旧文件，写入失败会保留当前窗口供重试。强制结束或断电可能回退最后几秒。

## 升级

已有 GitHub 版可在右键或托盘的更新菜单检查新版。更新保留 `data`、`games`、`.update`，原养成进度与最佳成绩继续使用。

旧 0.6.1 没有棋盘存档，升级前正在玩的棋盘无法补存；从新版开始的新局才支持续局。原自定义游戏仍兼容旧接口，可按小游戏说明自行接入可选续局能力。旧极狐安装首次切换 GitHub，仍按迁移指南手动完整安装。

日常玩法离线，不需要账号或服务器。新游戏不改变金币、经验、体力和原有动作。
