# 0.9.0 本地试玩：小黑屋与 Candy Box 2

## 新增玩法

- **小黑屋**：生火、资源、建设、探索。默认简体中文，纵向排版，在现有小窗玩。
- **糖果盒子 2**：产糖、吃糖、解锁地图与装备，保留原作 ASCII 和中文提示。宽地图使用小窗内的滚动区域。
- 游戏总数增加至十六款，各自独立保存；两款均使用内置离线资源，无账号、服务器或新的运行语言依赖。

## 暂停与保存

- 打开后点击“继续游戏”。收起 / 失焦暂停，取消“失焦暂停”可在窗口打开期间挂机。暂停 / 程序退出时间不补算收益。
- 五秒自动保存，切走 / 关闭 / 正常退出时保存。原作普通数据通过网页消息交给现有原子存档接口；读取异常时保留原文件，明确确认新游戏才替换。
- 小黑屋保留原作 `State` 中的成长，事件 / 探索现场按原作加载规则处理。Candy Box 2 保留原生资源、装备与解锁字段，重开回到糖果页，当前战斗不逐帧续接。
- 不同游戏、桌宠养成互不覆盖。换电脑仍先正常退出，再复制整个 `data`。

## 运行与来源

三款网页游戏复用 WebView2 Runtime；原十三款 C# 游戏不要求此组件。资源和 SDK 嵌在 exe，旧版 ZIP 白名单保持兼容。原作完整代码、许可、上游版本和修改说明随程序及仓库提供，见 `third_party/*/NOTICE.md`。小黑屋 MPL-2.0，Candy Box 2 GPL-3.0-or-later，公共桌面脚本 MIT。
