## 怎么休息

在养成面板“小屋”的“午睡补元气”卡片，点击“去睡一小会儿”。也可从桌宠右键或托盘菜单进入睡觉和叫醒操作。

- 一次完整午睡 180 秒，叫醒后最多恢复 25 体力、4 心情，属性上限仍是 100。
- 随时可以“提前叫醒”，按已经睡过的时间比例恢复；例如睡 90 秒，恢复一半。
- 睡满后等你点击“叫醒哪吒”才结算。多等一会儿不会超过本次完整奖励，也不能重复领取。
- 睡觉期间暂停原有体力自然恢复和心情衰减，饱腹继续减少，避免午睡收益与自然恢复重复叠加。
- 关闭程序后睡眠记录仍保留；再打开并叫醒时，按保存的时间结算。
- 打工与休息不能同时进行；休息中先叫醒再喂食或接工作。点击身体仍会有提示，但不会增加互动经验。

## 为什么这样做

身体点击原先主要复用基础动作，玩家不容易感到“点头”和“点身体”的差别。这轮先补最常点击的部位，再保留可以继续扩展的动作配置。

休息给体力增加一个主动恢复的入口，让用户知道哪吒打工累了以后可以照顾它。规则与睡觉画面分开：睡觉动作负责表现，休息记录负责什么时候恢复、恢复多少和避免重复结算。

## 数据和动作怎么走

点击部位 → 判断当前动作是否允许互动 → 执行互动规则 → 保存结果 → 播放专属动作或特效 → 完成后恢复当前状态。

开始休息 → 检查是否能休息 → 保存开始时确定的休息快照 → 播放睡觉 → 玩家叫醒时按已休息的时间结算 → 清除休息记录并保存。

正在播放的吃东西和有限互动动作有自己的结束时间。动作结束前，新点击、喂食、出发打工和睡觉会提示稍等，本次请求不扣物品也不结算奖励。购物可以继续，购物提示只显示文字，不把正在播放的动作切走。

存档写入沿用“临时文件 → 完整写入 → 替换正式存档 → 保留备份”的方式。若写入失败，本次内存中的体力、背包和状态变化会退回；不把保存失败当成操作成功。

## 更新与存档

0.3.1 使用者在更新菜单检查已发布的新版本。下载、校验与安装仍由原有更新助手完成，更新包替换程序、素材和配置，`data` 存档继续保留。

0.1 / 0.2 还没有一键更新，需要退出后将新版完整解压到新目录，并在首次启动前复制旧版整个 `data` 文件夹。保留旧目录，确认新版进度正常后再清理。

0.4.0 存档格式升级到 3，新增休息记录。格式 1 / 2 存档自动迁移，保留金币、背包、累计经验和已接工作。休息记录保存开始时间、截止时间、当时的体力/心情奖励和动作，后来修改配置不会追溯改变这一次休息。

升级后的格式 3 存档不能交给 0.3.1 及更早程序使用。回退时使用保留的旧版目录与它原来的存档。
