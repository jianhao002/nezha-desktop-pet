# 焰轮哪吒 v0.8.2

新增“格子王国 · Gridland”，内置游戏增至十四款，并包含家庭试玩反馈后的中文提示和死亡重试修复。

## 格子王国

- 在原小游戏小窗中离线运行，交换相邻格子形成三消，白天收集资源、建设，夜间战斗。
- 中文菜单、静音启动，沿用透明度、置顶、切走暂停和一键收起。
- 保存棋盘、资源和成长、昼夜进度、人物 / 怪物血量与位置、法术剩余时间；关闭后重开，点击“继续游戏”恢复。
- 修复保存遮罩和中文弹框乱码。角色倒下后显示提示并暂停，点“继续”才重试；关闭重开仍保留死亡提示，连续点击不会重复启动重试。

## 安装与升级

已有 GitHub 版从宠物右键或托盘的更新菜单检查并安装新版。第一次安装则完整解压 ZIP，再双击 `NezhaPet.exe`。升级保留 `data`、`games` 和 `.update`；本局、养成进度与最佳成绩仍在本机保存。

格子王国需要 Microsoft Edge WebView2 Runtime（嵌在小窗里的浏览器引擎），本机已有时直接使用；缺少时会提示，其余十三款游戏仍可使用。运行不需要 Git、Python、Node.js、GPT 账号或服务器。旧极狐版第一次切换 GitHub，仍按仓库迁移说明手动完整安装。

网页、图片和 WebView2 SDK 随 exe 内置，安装包沿用旧版程序 / 配置 / README / 素材白名单。Gridland 原作者为 doublespeak games / Michael Townsend，原源码与桌面适配源码保留 MPL-2.0；原许可及 WebView2 LICENSE / NOTICE 随程序与公开仓库提供。

## 续局边界

恢复时重新计算短暂的攻击、建设和搬运动画；正在搬运的资源计入保存的仓库，临时飞行投射物不保存。原游戏的“导出成长”不含桌面完整棋盘 / 战斗快照，迁移到其他电脑仍需正常退出后复制整个 `data`。每五秒自动保存，强制结束进程或断电可能回退最后几秒。

本版保持原有哪吒金币、经验、食物、工作和动作规则，不增加联网奖励。Windows x64 的本机验证和家庭试玩记录已提供，ARM64、其他显示缩放与多显示器仍需目标机器验收。
