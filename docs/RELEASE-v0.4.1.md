# 0.4.1：互动、午睡与可更新的发布包

0.4.1 包含 0.4 的摸头、挠痒、睡觉动作，神环呼吸光、风火轮拖尾、动作保护和午睡恢复体力。玩法说明见 `RELEASE-v0.4.0.md`，后续路线见 `ROADMAP.md`。

## 修正发布链路

实际桌宠下载 0.4.0 时，安全校验拒绝了 ZIP 内的反斜杠路径。原因是不同 Windows PowerShell / .NET 版本默认生成的 ZIP 路径分隔符不同；之前的集成测试验证的是测试夹具生成的包，没有覆盖最终打包产物。

这轮保持更新安全规则，修正打包流程：

1. 打包时逐文件创建条目，明确把路径写成标准 ZIP 的 `/`，避免依赖框架默认行为。
2. 最终 ZIP 生成后，用 `NezhaPet.exe --package-check` 调用实际更新按钮使用的 `UpdateSafety.ExtractPackage`，检查路径、文件白名单、版本和完整解压。
3. 这个关卡失败就停止打包，不生成可发布清单。
4. 上传较大的包允许等待 180 秒；上传流关闭失败不会遮住原始网络错误。
5. 版本包保持不可覆盖：已上传的 0.4.0 保留历史，用户从最新更新清单获取 0.4.1。

## 使用方法

0.3.1 使用者右键桌宠 → 检查更新 → 下载并安装 0.4.1。更新先保存进度，替换程序与素材，保留 `data`，启动时把格式 1/2 存档迁移到格式 3。

0.1 / 0.2 / 0.3.0 使用者退出桌宠，将 0.4.1 完整包解压到新目录，首次启动前复制旧版整个 `data` 文件夹。其他电脑、多显示器与不同缩放比例仍需实机试用。
